# Objetivo e Escopo

## Objetivo

Organizar conhecimentos sobre Inteligência Artificial Generativa aplicada ao desenvolvimento de software utilizando o Google NotebookLM.

## Escopo

O projeto aborda quatro áreas principais:

- Agentes de Inteligência Artificial
- Automação com n8n
- IA aplicada à programação
- Integração com APIs de LLMs

## Ferramenta principal

Google NotebookLM.
