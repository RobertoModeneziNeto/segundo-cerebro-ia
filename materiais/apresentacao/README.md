# Apresentação — IA Generativa aplicada ao Desenvolvimento de Software

Esta pasta contém a apresentação em PDF produzida durante o desenvolvimento do projeto **Second Brain**, como parte do Bootcamp de Inteligência Artificial DXC.

## Objetivo

Apresentar os principais conhecimentos organizados no Second Brain, demonstrando como a Inteligência Artificial Generativa pode ser aplicada ao desenvolvimento de software, desde a construção de agentes inteligentes até a automação de processos e integração com APIs de modelos de linguagem.

## Conteúdo

A apresentação aborda cinco áreas principais:

1. **Agentes de IA:** conceitos, arquitetura e utilização de agentes inteligentes.
2. **Automação com n8n:** criação de fluxos automatizados e integração entre serviços.
3. **Desenvolvimento assistido por IA:** utilização de ferramentas de IA para apoiar a programação.
4. **Integração com APIs de LLMs:** comunicação entre aplicações e modelos de linguagem.
5. **Segurança e confiabilidade:** cuidados, limitações e boas práticas no desenvolvimento de soluções com IA.
